Campus Events Guide Website
A beginner-friendly, responsive campus events website built for Zewailians (Zewail City students). It helps students explore campus events, view a featured event, check the timetable, and try a registration form.
Project Pages
- index.html — Home page with an introduction and featured events.
- events.html — Events catalogue.
- event-details.html — Details for the featured AI and Technology Workshop, including an agenda and review form.
- schedule.html — Campus events timetable.
- registration.html — Registration form demonstrating HTML5 form controls and browser validation.
- style.css — Shared styles for the website.
- assets/ — Folder for local images, audio, and video files.
Technologies
- HTML5 for page structure and content
- CSS3 for styling, layout, responsiveness, and the CSS-only dark-mode toggle
This project is intended to use HTML and CSS only. It does not use JavaScript, frameworks, or external libraries. The forms are front-end demonstrations: they do not store or send submissions to a server.
How to Open the Website
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in a web browser such as Google Chrome or Microsoft Edge.
4. Use the navigation links to visit the other pages.
5. Resize the browser window to check the responsive layout and test the dark-mode checkbox.
No build step or package installation is required.
Media and Images
Place any local image, audio, or video files in the assets/ folder and make sure the file paths in the HTML match the real filenames. Do not create empty placeholder media files. If a referenced media file is missing, its audio or video player will not have playable content.

Some images may use external URLs, so they require an internet connection to load.
Assignment Goals
The website is being developed for a university HTML and CSS assignment. The main goals include:
- Semantic HTML5 page structure
- Consistent navigation and shared footer across pages
- Event information that matches across the home, catalogue, details, and schedule pages
- Responsive layouts using CSS Grid and Flexbox
- Accessible image alternative text and form labels
- HTML5 form validation
- A CSS-only dark-mode toggle
- One shared external stylesheet
